# LEGOLAND Discovery Center Bay Area Scavenger Hunt Web App
Small personal project!

## Purpose
At LEGOLAND Discovery Center, we have scavenger hunts where guests can search for hidden minifigures throughout our awesome Miniland exhibit. However, parents would have to take pictures of each minifigure and the scavenger hunt paper. This can be quite the hassle for both parents and employees, as we have to stand there and watch them scroll through many photos. Not only that, but a lot of employees don't know how many minifigures are in each hunt. I wanted to create this web app to make it simple for guests to complete our scavenger hunt, and it also makes it easier for our employees to give them their prizes, as they can easily see when a hunt is fully finished!

## Notes
This project has no relation to LEGOLAND Discovery Center Bay Area. It is simply a small personal project I wanted to work on to develop my front-end skills. Thanks for checking it out!
